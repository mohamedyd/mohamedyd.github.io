CONNX is Software AG's enterprise data-connectivity middleware, providing unified, SQL-based access to heterogeneous and legacy data sources — including mainframe stores such as Adabas and VSAM, and relational databases such as SQL Server, Oracle, and Db2 — through a single interface and a federated metadata catalogue.

The CONNX AI initiative explores how large language models and AI agents can discover and query this federated data using natural language, built on the open Model Context Protocol (MCP). Rather than copying data into a separate AI platform, the goal is to make the existing, governed data gateway the safe entry point for AI.

A central theme of the work is trust: enabling AI access to sensitive enterprise data only when identity, authorization, auditing, and data-protection controls are demonstrably enforced. The initiative also emphasizes on-premise and locally hosted models, so sensitive data never has to leave the customer's environment.
